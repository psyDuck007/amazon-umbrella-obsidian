# 退货标签规则

## 适用场景

买家坚持退货、商品无法通过已确认方案解决，或平台流程需要买家退回伞体箱、底座箱或其他包裹。

## 一、申请标签前收集信息

向客户收集以下最小信息，用于确定退货仓库、标签数量和退货方式：

1. `2-3` 张清晰的完整包装照片，用于判断包裹尺寸、封箱和当前包装状态。
2. 确认伞体和底座是否拆封或组装过。
3. 确认底座是否灌过水、沙或其他填充物，以及是否已经排空。

以上信息不影响客户提出退货，主要用于确定退货仓库、标签数量和退货方式。组装过本身不阻止提出退货。底座灌装状态可能影响承运、退回方式和最终退款范围，但不能仅根据客户情绪自动决定退款；客户情绪只影响首封邮件的表达顺序，最终结果按人工判断或审批执行。

请求资料时不得写成“不提供照片就不能退款/退货”。

## 二、标签与包裹映射

- 先确认退货对象：整套、伞体箱、底座箱或其他包裹。
- 每个退货包裹使用一张独立标签；标签数量必须与需要退回的包裹数量一致。
- 伞体标签只能贴伞体包裹，底座标签只能贴底座包裹；不得交换。
- 如果包裹角色、标签映射或数量不清楚，停止生成确定性贴标说明，转人工确认。
- 对客只使用真实标签和真实 tracking，不根据附件顺序或文件名猜测。

## 三、发送标签时的固定提醒

- 使用卖家提供的 `prepaid FedEx return label`；不要同时贴其他退货标签。
- 粘贴新标签前，移除或完全遮盖旧运输标签、旧退货标签和其他可扫描条码。
- 新标签应平整、完整可见，不贴在箱体接缝或开口处，不被胶带或其他条码遮挡。
- 明确提醒每张标签必须贴到对应包裹，贴错可能造成 FedEx 扫描、仓库识别或退款流程延迟。
- 不使用 `free` 表述，统一使用 `prepaid`。

## 四、贴标后照片确认

- 请求客户为每个退货包裹发送一张贴好新标签后的清晰照片。
- 照片尽量同时显示完整包裹、新标签位置，并确认没有暴露旧标签或旧条码。
- 照片数量按实际包裹数量动态生成，不固定写“两张”。
- 目的写成帮助核对标签与包裹对应关系、减少扫描或识别延迟；不得以照片作为威胁退款的条件。

## 五、交寄与上门取件

- 客户可将已贴标包裹送至 FedEx 网点；大件搬运不便时，可在已确认可用的情况下安排 FedEx 上门取件。
- 只有真正完成预约后，才能写预约日期、时间窗和 pickup confirmation number / PIN。
- 建议保留交寄收据或上门取件确认。

## 六、退款跟进

- 根据当前订单决定退货后退款、部分退款或其他已批准方案，不从旧案例复制金额。
- 仓库确认收到并完成必要处理后，通过 Amazon 处理退款。
- 不承诺固定到账天数；使用当前订单后台或 Amazon 当时显示的真实时效。
- 退款处理完成后再向客户发送确认，不提前写成已退款。

## 风险边界

- 不自行选择退货仓库。
- 不自行判断已灌装底座一定可退或一定不可退。
- 不要求客户继续搬运存在明显安全风险的包裹。
- 不在客户邮件中提及内部数据库字段、规则编码、物流部门或审批细节。
- 不把退款、退货标签或上门取件与评价、评论、星级或公开内容修改绑定。

## 待确认

- 当前订单需要退回的包裹数量和角色。
- 标签与包裹的真实映射。
- 底座灌装状态、是否已排空及承运条件。
- 退货仓库、承运商和上门取件安排。
- 当前订单退款授权与到账时效。
