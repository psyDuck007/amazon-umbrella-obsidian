# C部件拆卸问题

## 适用场景

买家在安装或拆解罗马伞时反馈 `C 部件` / `Part C` 套在主伞杆上，无法顺利拆下、滑出或移动。

当前适用于 JZAC / QZYD 悬臂罗马伞中存在 `C 部件` 连接管结构的售后排障。具体 ASIN、尺寸、颜色和批次需要结合订单、说明书或买家图片确认，不得默认扩展到所有型号。

## 问题类型

- 组装拆卸排障。
- 结构件卡滞。
- 运输保护、喷涂厚度或轻微挤压导致的装配阻力。
- 买家预期管理和安全操作提醒。

## 处理原则

1. 先提醒买家不要强行拉拽或斜向撬动，避免刮伤主杆或让部件更卡。
2. 先确认遮阳伞完全收合，并建议把伞体平放在地面、地毯或纸板上。
3. 先检查所有固定件是否完全松开，包括侧边螺丝、垫片、黑色旋钮、锁紧件、定位销和底部圆形连接盘附近的螺丝。
4. 松开后用左右小幅晃动和直线滑出的方式处理，不建议直接用蛮力外拔。
5. 若仍无法拆下，索要清晰照片或短视频，再判断是否属于安装误解、运输挤压、部件变形或需要补发/退货处理。

## 中文排障步骤

### 拆卸前准备

- 请先确认遮阳伞处于完全收合状态，不要打开伞面。
- 建议把伞体平放在地面、地毯或纸板上，避免刮伤伞杆和地面。
- 如果 `C 部件` 卡得比较紧，建议两个人配合操作：一个人扶住主杆，另一个人拆卸 `C 部件`。

### 第一步：找到 C 部件与主杆的连接位置

`C 部件` 通常是套在主伞杆上的灰色方管或连接管。它可能会因为运输保护、喷涂厚度或轻微挤压，看起来像“卡死”在主杆上。

请先检查 `C 部件` 靠近主杆的位置，确认是否有：

- 银色固定螺丝。
- 黑色旋钮或锁紧件。
- 小定位销。
- 底部圆形连接盘附近的螺丝或垫片。

这些固定件如果没有完全松开，`C 部件` 无法顺利拆下。

### 第二步：先松开侧边固定螺丝

使用包装内附带的内六角扳手或合适工具，找到 `C 部件` 侧边的小螺丝。

将螺丝逆时针旋转，先完全松开。如果螺丝已经顶住主杆，不要只松开几圈，建议将螺丝和垫片先取下来，放在一旁保存好。

注意：不要在螺丝还顶着主杆的情况下强行拉 `C 部件`，否则容易刮伤主杆或让部件更卡。

### 第三步：检查底部圆形连接盘附近的螺丝

如果 `C 部件` 仍然无法移动，请检查主杆底部圆形连接盘附近是否还有固定螺丝。

按照视频或说明书里的方式，把连接盘周围可见的固定螺丝依次逆时针松开。松开后，轻轻取下螺丝和垫片，并放在一起，避免丢失。

关键点：只要还有一颗螺丝没有完全松开，`C 部件` 就可能无法滑动或取下。

### 第四步：扶稳主杆，轻轻左右晃动 C 部件

螺丝全部松开后，一只手扶住主杆，另一只手握住 `C 部件`。

不要直接用蛮力往外拔。正确方式是：

1. 先轻轻向内推一下 `C 部件`，让卡住的位置松动。
2. 然后左右小幅度晃动。
3. 保持 `C 部件` 和主杆在同一条直线上。
4. 再慢慢向外滑出或向上取下。

如果拉的时候感觉卡住，不要斜着撬，也不要用金属锤敲。

### 第五步：如果仍然很紧，可以轻拍辅助松动

如果 `C 部件` 还是很紧，可以用手掌或橡胶锤轻轻拍打 `C 部件` 的外端，让它慢慢松动。

注意：

- 不要用铁锤直接敲。
- 不要敲黑色把手或塑料件。
- 不要用螺丝刀强行撬开。
- 不要用润滑油、汽油或腐蚀性清洁剂。

如果需要，可以在连接缝隙处轻轻左右晃动几次，再重新尝试直线抽出。

### 第六步：取下后检查主杆和 C 部件

`C 部件` 拆下后，请检查：

- 主杆表面是否有明显变形。
- `C 部件` 内侧是否有异物。
- 螺丝孔是否对齐。
- 螺丝、垫片是否完整保留。

确认没有问题后，再按照说明书的安装步骤，把 `C 部件` 重新安装到正确位置。

## 合规与风险边界

- 不要把 `C 部件` 卡住直接写成产品缺陷；先按安装、固定件未松开、运输挤压或结构件卡滞排查。
- 不要承诺未确认的补发、退款、退货或赔偿；需结合照片、视频、订单和库存判断。
- 不要引导买家站外沟通；要求图片或视频时使用 Amazon Buyer-Seller Messaging。
- 不要建议使用金属锤、螺丝刀强撬、润滑油、汽油或腐蚀性清洁剂。
- 如果买家反馈主杆明显变形、连接盘变形、塑料件破裂或存在安全风险，应建议暂停继续安装，并升级为结构故障证据判断。
