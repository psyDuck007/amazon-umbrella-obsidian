# 场景图规则

## 适用场景

用于 Amazon 副图、A+、品牌站入口图、广告素材及 AI 图像生成/修改。

## 必要输入

| 输入 | 来源 | 是否必需 | 备注 |
|---|---|---|---|
| 产品真实外观和版本 | 实拍、产品事实库 | 是 | 尺寸、颜色、灯光、底座、单顶/双顶不得混用 |
| 目标渠道与画幅 | Amazon / 品牌站 / 广告 | 是 | 明确主图、副图、A+、4:3 入口或横幅 |
| 目标住宅与使用场景 | 订单分布、客户图、场景研究 | 是 | 不默认只使用豪宅 |
| 参考图的用途 | 用户说明 | 是 | 明确参考构图、材质、把手、光影或庭院风格 |

## 已确认规则

- 美国主流住宅场景应包含普通一至两层住宅、真实后院、泳池边、露台、deck 等可落地环境，不把全部画面做成极端豪宅。
- 客户图可以作为风格参考，但不能只根据少量评论区图片推断全部州或全部客户偏好。
- 场景图应服务于遮阳、休闲、聚会、泳池、户外用餐、傍晚灯光等明确用途，同时保持产品版本真实。
- 没有真实仓库、客户项目、安装案例或团队证据时，不得用 AI 图或素材图暗示这些内容是真实案例。
- 当系列产品图尚未准备好时，可以先做不出现产品的 4:3 场景入口图，但必须标记为品牌氛围入口，不能冒充具体产品实拍。

## 图像修改边界

- 用户要求只修改伞骨/伞柱木纹时，其他主体、比例、构图和背景保持不变。
- 用户要求替换把手时，保持目标把手比例，并让材质、方向、阴影和环境光与原图一致；不顺带修改其他部件。
- 每次修改前明确“可变元素”和“保持不变元素”，防止 AI 重绘产品结构。
- 参考图中的未确认配件、纹理、灯光或功能不能自动复制成产品事实。

## 禁止事项

- 不虚构客户家、真实项目、美国仓库、门店、认证或团队背书。
- 不把单顶改成双顶、无灯改成带灯、非旋转改成旋转、无底座改成带底座。
- 不改变把手、伞柱、伞骨、底座或伞面的真实比例来制造不存在的功能。
- 不使用只适合豪宅的单一视觉代表全部客户。

## 输出要求

- 记录渠道、画幅、产品版本、场景、可变元素、保持不变元素和参考图来源。
- 对生成图进行结构、颜色、灯光、底座、透视、手柄和品牌文字检查。
- 未确认是否为真实实拍时，标记为概念图/生成图，不作为产品证据。
