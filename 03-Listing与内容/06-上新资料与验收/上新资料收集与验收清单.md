# 罗马伞上新资料收集与验收清单

## 适用范围与状态

- 适用于 JZAC & QZYD Amazon US 罗马伞的新链接、拆分尺寸链接及新增颜色变体。
- 本页的移动端验收标准和资料收集顺序为 `2026-08-13 用户指定执行标准`，不是某一 ASIN 的产品事实。
- 本页列出的数字或能力字段均须逐个对应到尺寸、颜色、灯光版本、是否带底座和 ASIN/SKU；未取得证据前统一标记 `待确认`，不得写入标题、图片、五点、A+、后台属性或客服承诺。

## 上新放行门槛

在开始文案、作图或上传后台属性前，先建立一份“变体参数主表”。每一行至少应能唯一定位为：

`父体/链接 + 子体 ASIN/SKU + 尺寸与形状 + 颜色 + 灯光版本 + 是否带底座 + 底座型号 + 证据来源/日期`

未能定位版本时，停止发布；不能用同系列、另一颜色或另一尺寸的参数代替。

### A. 伞面与面料资料

| 必收字段 | 需记录的证据/口径 | 发布前判断 |
|---|---|---|
| 面料材质 | 材质名称、供应商规格书或适用型号 | 不能把通用 `polyester` 延伸为未证实的具体工艺或等级 |
| 面料克重 | `GSM` 数值、测试/规格文件、适用变体 | `240 GSM`、`250 GSM` 仅是待收集示例，不是现有产品参数 |
| 防水性 | 测试方法、等级/结果、适用产品和允许的英文表述 | 无明确等级时，不写具体防水等级或 `100% waterproof` |
| UV 防护 | UPF 测试结果、测试标准、适用面料/颜色 | `UPF 50+` 只能在有对应报告时使用 |
| UV 阻隔率 | 阻隔率、测试方法、适用产品 | 不可由 UPF 示例或其他型号推导到当前变体 |
| 双顶透气性 | 是否为双顶、通风结构说明及可用表述 | 只描述已确认结构；不推导为抗风承诺 |
| 可拆卸/可更换 | 可拆卸部位、替换件 SKU、安装边界、说明书 | 未确认前不得写 `replaceable canopy` 或承诺可单独更换 |

### B. 灯光系统资料

| 必收字段 | 需记录的证据/口径 | 发布前判断 |
|---|---|---|
| 供电方式 | Solar、Power Bank、充电电池或其他；输入/接口/包装内容 | 不得把一种供电方式复制到其他灯光版本 |
| 伞骨灯/灯珠 | 灯光布局、灯珠数量、适用版本 | 不展示或描述实际不存在的灯珠布局 |
| 中心灯 | 是否有、位置、数量和独立开关关系 | 全灯、半灯、无灯必须分开确认 |
| 灯光颜色 | 实际色温/颜色、是否可切换 | 不把暖光、白光或多色温互相替代 |
| 亮度/色温调节 | 档位数量、每档定义、控制方式 | 未确认前不写“多档”“3档”或可调色温 |
| 续航 | 测试条件、亮度档位、满电/日照条件、时长 | 不写脱离测试条件的笼统续航承诺 |
| 开关位置 | 物理位置、图示和操作说明 | 图片、五点、说明书口径一致 |

### C. 尺寸、结构与空间资料

参考用户提供的尺寸示意图，对每个尺寸建立以下字段；图中出现的 `8x8 / 9x9 / 9x12 / 10x13` 和面积数字只作版式示例，不作为本产品参数。

| 分类 | 必收字段 |
|---|---|
| 整伞 | 整伞总高度、主杆高度、横臂长度、伞下净空高度、伞面最低点高度 |
| 伞面 | 伞面长度、伞面宽度、伞面面积、尺寸/形状 |
| 悬臂结构 | 伞中心到主杆距离、主杆截面宽 × 高、横臂截面宽 × 高 |
| 收拢状态 | 收拢后总高度、收拢后占地宽度 |
| 底座 | 底座长、宽、高、占地面积、是否包含、适用填充/配重资料 |
| 实际使用 | 阴影覆盖面积的适用条件、360° 旋转所需空间/旋转直径 |

记录测量单位、测量位置、允许误差、图纸/实测来源和适用 SKU。阴影面积会随太阳角度变化，不能把示意面积写成固定保证。

## 移动端三档验收

| 宽度 | 定位 | 必检项 | 放行标准 |
|---|---|---|---|
| `360 px` | 最低兼容标准 | 主图与副图文字、关键尺寸标注、按钮及页面主体 | 图片和页面信息清晰可辨，不截断、不重叠、不因压缩而无法理解 |
| `400 px` | 主流手机标准 | 标题长度和换行、图片排版、文字密度、首屏节奏 | 阅读和浏览舒适；标题不显得拥挤，图片说明不挤压主体 |
| `420 px` | Pro Max 等较宽屏重点标准 | 高端大伞链接的主图、副图、尺寸/场景布局 | 页面和图片不留大块无意义空白，仍保持高端大尺寸产品的完整感 |

- `390 px` 与 `402 px` 作为接近 iPhone 实际宽度的补充抽检点；不能替代上述三档。
- 验收必须覆盖：父体落地页、每个尺寸、每个颜色、带/不带底座、灯光差异版本，以及图片放大后的文字可读性。
- 留存每档的页面截图、设备/浏览器、检查日期、发现问题、修改版本与复测结果；没有实机或预览证据时，状态为 `待验证`。

## 同父体的内容一致性与差异化

### 一致性优先

- 目标是让买家在同一链接内理解为同系列产品，并在符合 Amazon 变体政策的前提下减少不必要的内容差异；不能把“评论共享”当作必然结果或通过不实属性强行合并变体。
- 标题、五点、图片、A+、后台属性和包装信息应共享已确认的共性；只在尺寸、形状、颜色、灯光版本、底座版本及其真实参数处作必要差异化。
- 任何共享文案都必须先通过“变体参数主表”逐项核对。尤其不可跨版本复制：底座包含情况、灯珠/中心灯、供电方式、GSM、UPF、UV 阻隔率、防水等级、续航和可替换性。

### 标题与投词的颜色差异化：待验证策略

- 在不牺牲品牌、尺寸、品类词、灯光和底座版本识别的前提下，可为颜色变体分配一个不同的、真实相关的场景词，避免各子体标题与后台词完全同质。
- 初始候选：Beige 可测试 `outdoor`，Grey 可测试 `backyard`；这只是投词/标题差异化假设，不代表词与颜色存在已验证的固定对应关系。
- 广告中把相应场景词投向能正确承接的颜色变体，不能用不匹配颜色来承接搜索意图，也不能因为词不同而改变实际产品属性。
- 以搜索词报告和广告数据验证：Impressions、CTR、CVR、Orders、CPC、ACOS、自然订单；先观察 `7-14` 天或足够样本，再保留、替换或撤回该颜色词。样本不足或结果相互矛盾时标记 `无结论`。
- 关键词应优先由往年真实出单词反查：按尺寸、颜色、底座/灯光版本清洗后，选高相关且可由该变体承接的词；不把历史出现过但不相关、已重复或会误导版本的词硬埋进标题/后台词。

## 分尺寸作图硬性要求

- 每个尺寸必须单独作图，不能仅替换尺寸文字后复用同一比例场景。
- 主图/场景图中应通过同类庭院家具、人物、活动区或俯视覆盖图，直观表现 9x9、9x12、10x13 的形状与实际大小差异；矩形长边方向必须准确。
- 大尺寸图必须表现其明显覆盖范围，但不得夸大伞面、阴影、立柱、横臂或底座比例。
- 至少提供：展开侧视尺寸图、展开俯视/旋转空间图、收拢状态图、主杆与横臂截面图、底座尺寸图、伞面尺寸/覆盖参考图。若某部件或底座不包含，图上必须按实际版本说明。
- 图上尺寸、面积、旋转范围、防护与灯光文案均须回填至“变体参数主表”核验；无法核验则不出图或使用 `待确认` 内部占位。

## 上线前最终签核

1. 参数主表与供应商资料、测试报告、包装清单逐项一致。
2. 标题符合现有 `75` 字符规则，并已完成 360/400/420 px 检查。
3. 各变体的图片、五点、A+、后台属性和广告落地页相互一致。
4. 不带底座版本没有被图片或关键词误导为带重型填充底座。
5. 灯光、面料、UV、防水、可拆换等受控表达均有对应证据。
6. 尺寸图展示真实差异且单位、方向、面积/旋转说明可追溯。
7. 颜色场景词测试已记录基线、动作与复盘窗口；未验证时不固化为长期规则。
