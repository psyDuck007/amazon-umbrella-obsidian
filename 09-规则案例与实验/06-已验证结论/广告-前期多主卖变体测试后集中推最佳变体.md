# 广告-前期多主卖变体测试后集中推最佳变体

## 状态

- 结论状态：已验证
- 记录日期：2026-07-06
- 来源：用户运营经验
- 适用模块：广告运营、变体广告策略、推新品、主卖变体选择、自然流量获取

## 原始结论

前期推广告时，如果有多个主卖变体，在前期约一星期测试后，应分析广告数据，选出数据最好的那个主卖变体。后续所有广告尽量集中去推这个变体，集中广告权重，使该变体更快获得更多自然流量。

## 适用条件

| 条件 | 说明 |
|---|---|
| 多个主卖候选变体 | 例如不同颜色、尺寸或带底座版本都可能承担主流量 |
| 已完成前期测试 | 通常至少完成约 `7` 天广告测试 |
| 数据可比较 | 各变体有相近或可解释的曝光、点击、花费和订单样本 |
| 产品承接一致 | 搜索词、尺寸、灯光、底座和颜色需求能被候选变体正确承接 |

## 核心判断指标

选择主推变体时，不只看订单数，应综合：

| 指标 | 判断用途 |
|---|---|
| Spend | 判断广告消耗和拿量能力 |
| Clicks | 判断是否有足够测试样本 |
| Orders | 判断直接成交能力 |
| Sales | 判断销售贡献 |
| ACOS | 判断广告效率 |
| CVR | 判断点击后的转化承接 |
| CPC | 判断拿量成本 |
| CTR | 判断前台吸引力 |
| 自然订单变化 | 判断广告集中后是否带动自然流量 |

## 操作规则

1. 前期 `7` 天内，让多个主卖候选变体都有基本测试机会。
2. 测试结束后，按广告订单、ACOS、CVR、CPC、CTR 和自然订单变化选出表现最好的主卖变体。
3. 将核心词、精准长尾词、主要预算和优质广告位尽量集中到该主卖变体。
4. 对非主推变体保留少量必要测试、防守或清库存预算，不再平均分散主预算。
5. 集中投放后继续观察 `7-14` 天，判断该变体自然流量、自然订单和整体广告效率是否改善。

## 预期效果

- 减少广告预算在多个变体之间平均分散。
- 集中订单和点击信号，提高主卖变体权重。
- 更快带动该变体的自然流量和自然订单。
- 让广告结构更清晰，便于后续判断词、广告位和预算动作是否有效。

## 风险边界

- “所有广告尽量集中”不等于完全关闭所有其他变体广告；防守、清库存、低成本测试和特定长尾词承接仍可保留。
- 如果搜索词明确指向某个尺寸、底座、灯光或颜色需求，必须由能正确承接的变体投放，不能为了集中权重而投给不匹配变体。
- 如果最佳变体库存不足、价格无优势、Review 明显弱或 Listing 承接差，不应盲目集中全部预算。
- `7` 天测试期样本不足时，不应强行定主卖，应延长测试或降低结论强度。
- 该规则适用于前期主卖变体选择和推新品，不等同于稳定期所有变体长期只推一个。

## 复盘指标

| 指标 | 观察周期 | 判断方式 |
|---|---|---|
| 主推变体广告订单 | 集中后 `7-14` 天 | 是否上升 |
| 主推变体自然订单 | 集中后 `7-14` 天 | 是否随广告集中同步上升 |
| 主推变体 ACOS / CVR | 集中后 `7-14` 天 | 是否保持或改善 |
| 其他变体订单损失 | 集中后 `7-14` 天 | 判断是否牺牲过大 |
| 父体总订单 | 集中后 `7-14` 天 | 判断集中推是否带动整体增长 |
| 核心词自然排名 | 集中后 `7-14` 天 | 判断权重是否改善 |

## 待补数据

- “数据最好”的优先级公式：订单、ACOS、CVR、CPC、CTR、自然订单各自权重。
- 集中投放后自然流量提升的量化判断方式。
- 需要保留给非主推变体的最低测试预算比例。
